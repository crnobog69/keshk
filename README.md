# Keshk

Минималистичка веб апликација за праћење месечног буџета. Буџет делиш на **Кешкиће** (омотнице са новцем), трошкове додељујеш одређеном Кешкићу, а за куповину правиш **листе** чији збир једним кликом одузимаш од Кешкића.

Једна Go бинарна датотека (веб интерфејс је уграђен), SQLite база, без спољних сервиса. Ради на Windows-у, Linux-у и на Raspberry Pi 5.

## Могућности

- **Месечни преглед** – преостали износ, потрошено у процентима, дневни лимит и историја последњих 6 месеци.
- **Кешкићи** – сваки има свој износ и валуту. Живи из месеца у месец док га не одбациш; може бити подразумевани.
- **Трошкови** – у RSD, EUR или USD, са курсом по ком је трошак унет. Могу се мењати и брисати.
- **Листе за куповину** – производи са опционом ценом, штиклирање купљеног и измена сваке ставке (оловка или двоструки клик на назив). „Одузми од Кешкића” прави трошак од збира купљених ставки, а може се и поништити.
- **Извоз / увоз** – резервна копија свих података у једној JSON датотеци (мени налога → *Извези податке* / *Увези податке*).
- **Профил корисника (`/u/@корисник`)** – профилна слика и позадина преко линка, име за приказ, опис и датум од када је члан (видљиво само пријављеним корисницима).
- Светла и тамна тема, промена лозинке, заштита пријаве од погађања лозинке.

## Брзо покретање

Потребан је [Go](https://go.dev/dl/) (верзија из [go.mod](go.mod)).

```bash
./run.sh
```

```powershell
.\run.ps1
```

Скрипта при првом покретању прави `.env` из `.env.example` (са насумичним `SESSION_SECRET`), компајлира апликацију и покреће је на **http://localhost:3000**. Подразумевана лозинка из скрипти је `keshk` – **промени је** пре него што апликацију изложиш мрежи.

### Ручно

```bash
cp .env.example .env        # па попуни KESHK_USERNAME и KESHK_PASSWORD
go run .
```

Без `.env` фајла апликација чита исте променљиве из окружења, па може да ради као самосталан бинарни фајл.

## Подешавања

Све се подешава у `.env` (или променљивама окружења):

| Променљива | Подразумевано | Опис |
|---|---|---|
| `KESHK_USERNAME` | – (обавезно) | Корисничко име |
| `KESHK_PASSWORD` | – (обавезно) | Почетна лозинка. Када је промениш у апликацији, важи она из базе |
| `SESSION_SECRET` | насумично | 64 hex знака за потпис сесија. Ако није постављен, сесије се бришу при рестарту. Генерише се са `./hex64.sh` / `hex64.ps1` |
| `PORT` | `3000` | Порт сервера |
| `DB_PATH` | `data/keshk.db` | Путања до SQLite базе |
| `COOKIE_SECURE` | `false` | Постави на `true` када апликација иде иза HTTPS-а |
| `DEFAULT_KESHKIC` | `5000` | Предлог износа за први Кешкић (RSD) |
| `FALLBACK_EUR_RSD`, `FALLBACK_USD_RSD` | `117.2`, `100` | Курс који се користи када живи курс није доступан |
| `KESHK_RESET_PASSWORD` | `false` | `true` враћа лозинку на вредност из `.env` (за случај да је заборавиш) |
| `KESHK_SEED` | `false` | `true` попуњава **празну** базу пробним подацима (види испод) |

### Пробни подаци

Да погледаш апликацију са садржајем, а да не дираш праву базу, покрени је са посебном базом:

```bash
DB_PATH=data/demo.db KESHK_SEED=true ./run.sh
```

```powershell
$env:DB_PATH = 'data/demo.db'; $env:KESHK_SEED = 'true'; .\run.ps1
```

Додаје 4 Кешкића (RSD, EUR и USD, један одбачен), око 20 трошкова у последња 3 месеца и 3 листе за куповину (отворена, већ одузета и без рока). Датуми се рачунају у односу на данас. Ако база већ има Кешкиће или листе, ништа се не додаје.

## Резервна копија: извоз и увоз

- **Извоз** преузима `keshk-backup-ГГГГ-ММ-ДД.json` са Кешкићима, трошковима и листама (укључујући ставке).
- **Увоз** *замењује* све тренутне Кешкиће, трошкове и листе садржајем датотеке, у једној трансакцији – ако датотека није исправна, ништа се не мења. Пре замене тражи се потврда.
- Налог (лозинка, слика, име за приказ) није део копије и остаје какав јесте.

Сирову базу можеш копирати и ручно – то је само датотека `DB_PATH` (уз `-wal` и `-shm` ако апликација ради).

## Пречице на тастатури

| Тастер | Радња |
|---|---|
| `N` | Нови трошак |
| `K` | Нови Кешкић |
| `L` | Листе / контролна табла |
| `T` | Текући месец |
| `←` `→` | Претходни / следећи месец |

## Распоређивање на Raspberry Pi 5

Са Windows-а можеш направити Linux ARM64 бинарни фајл:

```powershell
.\run.ps1 -Target rpi5
scp keshk-rpi5-arm64 .env pi@raspberrypi:~/
```

На самом Pi-ју `./run.sh` компајлира и покреће апликацију.

## Алати у репоу

| Датотека | Намена |
|---|---|
| `run.sh`, `run.ps1` | Компајлирање и покретање (Linux / Windows) |
| `reset-db.sh`, `reset-db.ps1` | Брише базу – **трајно уклања све податке**, прво направи извоз |
| `hex64.sh`, `hex64.ps1` | Генерише 64 hex знака за `SESSION_SECRET` |
| `pull.ps1`, `push.ps1` | Помоћне скрипте за Git |

## Структура пројекта

```
main.go        рутирање и покретање сервера
config.go      учитавање .env / окружења
store.go       SQLite: Кешкићи, трошкови, месечни збирови
lists.go       листе за куповину и њихове ставке
transfer.go    извоз / увоз резервне копије
account.go     налог, лозинка, подешавања
auth.go        сесије, ratelimit.go – заштита пријаве
rates.go       курсна листа
web/           интерфејс (index.html, app.js, styles.css), уграђен у бинарни фајл
```
